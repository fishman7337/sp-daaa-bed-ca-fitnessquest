# Code of Conduct

## Our Pledge

Contributors and maintainers should make this project a respectful, harassment-free environment.

## Expected Behavior

- Be respectful and constructive.
- Give feedback that focuses on the work.
- Assume good intent while still correcting issues clearly.
- Protect private information, credentials, and coursework integrity.

## Unacceptable Behavior

- Harassment, insults, discriminatory language, or personal attacks.
- Publishing private credentials, personal data, or non-public coursework material.
- Deliberately introducing insecure or misleading code.

## Enforcement

Maintainers may remove comments, issues, pull requests, or contributors that violate this code.
